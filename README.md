# MusicTagEditor
Этот скрипт я хотел создать исходя из своих потребностей
В последнее время пришлось перейти на музыку, скачанную из интренета, но когда я присылаю её в телеграм и вижу "Неизвестный исполнитель - неизвестно 1", то сразу печально становиться
Да, существуют как сайты так и приложения для **полуавтоматического** редактирования метаданных треков, но на то я и выделил это слово. Что если у меня будет попадётся исполнитель с дюжиной альбомов в каждом из которых по 10 треков? Я ведь целый день могу потратить на это. Поэтому и решил приблизиться к максимально возможному автоматизму редактуры тегов для музыкальных файлов
