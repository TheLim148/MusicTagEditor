# MusicTagEditor
Этот скрипт я хотел создать исходя из своих потребностей
В последнее время пришлось перейти на музыку, скачанную из интренета, но когда я присылаю её в телеграм и вижу "Неизвестный исполнитель - неизвестно 1", то сразу печально становиться
Да, существуют как сайты так и приложения для **полуавтоматического** редактирования метаданных треков, но на то я и выделил это слово. Что если у меня будет попадётся исполнитель с дюжиной альбомов в каждом из которых по 10 треков? Я ведь целый день могу потратить на это. Поэтому и решил приблизиться к максимально возможному автоматизму редактуры тегов для музыкальных файлов
***
**Upd**
Надо бы вспомнить основной функционал. У меня есть несколько модулей, один получает фингерпринт трека, другой отправляет его на сервер и получает ответ, к тому же перед этим запускает прокси, ибо я из России, сайт с API мне просто так не доступен. Дальше мы парсим нужные данные и редактируем сами теги. По моему всё, больше я не заморачивался и не делал каких-то супер фишек
***
Вроде бы всё перечислил, сейчас можно написать пару будущих планов, не учитывая тех, которые описал выше. Во всех возможных тегах я увидел, что можно вписать bpm и mood (тональность). У меня возникла идея написать автоопределитель тональности и темпа трека чтобы даже такую информацию вносить в метаданные звуковых файлов прощедших через меня, но как только я погрузился в это, так понял, что это будет очень тяжело. Конечно, уже есть подобные проекты, даже не один и с куда более широким функционалом, чем мои потребности. Лично мне хотелось бы написать своё, возможно, тоже буду расширять, так как просто определение тональности и bpm это конечно мощно, но довольно узко, в отличие от того, что мне может дать звуковой файл и звук в целом. Хотелось бы писать на C++/Rust. Они оба низкоуровневые, но Раст меня привлекает больше. С плюсами я уже немного знаком, а с его товарищем нет. К тому же над этими языками можно сделать надстройку для Python, своеобразную обёртку. Если не ошибаюсь Essentia точно также написана. Основа и вычисления на Плюсах и также есть обрёртка в виде библиотки Python

В каком формате я бы хотел хранить все треки?
```txt
music/
| - Валентин Стрыкало
|   | - Смирись и расслабься!
|       | - 01 - (...).mp3
|       | - ...
|       | - 04 - Рустем.mp3
|       | - ...
|       | - cover.jpg # вместо имени cover скорее всего будет айди альбома на сайте с API
|       | - tags.json
```
То есть придётся ещё делать функционал с проверкой существования папки и также с записью всех тегов всех треков в нужный файл. Посмотрим что выйдет
